CENTERAUTH · MCP + OAUTH

One token. Your profile.

This page acts as an MCP client to demonstrate the same OAuth flow an LLM host performs.

  1. Register an OAuth client and create a PKCE challenge.
  2. Sign in with a mock account and grant profile access.
  3. Exchange the authorization code for tokens.
  4. Call get_my_profile with an authenticated MCP request.
